# MINIMAX CODE ASCII Field

这是一个独立、零依赖的 Canvas 2D 实验，依据 OpenAI Codex Hero 当前公开生产 bundle 中的真实客户端算法进行 vanilla JavaScript 移植。

核心架构、交互参数、兼容策略和运行方式均记录在本文；仓库不包含研究归档、官方 bundle 或视频素材。

效果画布默认使用 `#68C0FF` 背景，不加载原站视频；背景和字符的颜色、不透明度均可独立调整，对应不透明度设为 `0%` 时该图层完全透明。所有页面控件都收纳在独立的可折叠参数面板中。

页面右侧提供可收起的实时参数面板。面板本身不会向流体场注入鼠标轨迹；关闭面板后可在完整画布上测试效果。

## 可调参数

- 外观与网格：背景色、背景不透明度、字符色、字符不透明度、字符阶梯、字号、网格间距、对比度、Gamma、刷新率和明暗平滑。
- 程序明暗场：扭曲频率、大结构频率、细节频率、扭曲强度和流动速度。
- Hover 与拖拽：Hover 半径、揭示强度、指针推力、拖拽速度增益、扩圈上限和拖拽阈值。
- 点击波纹：最大范围、厚度、速度、推力、密度、随机度以及三组缓动/衰减指数。
- 流体模拟：分辨率、扩散、扩散迭代、速度/密度耗散、压力投影和压力迭代。

“清空轨迹”只重置当前流体状态；“复制 JSON”导出当前配置；“截图 PNG”导出当前 Canvas。“导出包含背景”关闭时，PNG 保持透明且只包含 ASCII 字符；打开时，PNG 会使用当前背景颜色和背景不透明度。“恢复 Codex 基线”会恢复全部默认值。

## 运行

在本目录执行：

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## 渲染结构

1. 与官方当前实现一致，使用 CPU `Float32Array` 保存速度、密度、压力和散度，并执行扩散、两次压力投影、平流和耗散。
2. 离屏 Canvas 生成 `MINIMAX CODE ` 字形 Atlas；主 Canvas 只在固定规则网格上绘制字形，因此不会发生倒置或字符离格。
3. Hover 按真实指针位移注入速度和密度，拖拽按指针速度扩大半径，形成与官方相同的流体拖尾。
4. 点击在约 `255ms` 内按官方公式生成最大 `184px` 的随机扰动扩散环；环结束后残留密度继续按流体规则自然消散。
5. 静止初始状态密度为零，末位空格会遮掉全部字符。程序明暗场只作为字符选择数据，不改变纯蓝背景。

## 与 Codex 基线对齐的参数

- `contrast: 2`、`gamma: 0.5`、反转亮度
- `fontSize: 9`、`cellPadding: { x: 1, y: 2 }`
- 字符场 `30fps`、明暗平滑 `1000ms`
- Hover 半径 `28px`
- 点击范围 `184px`、厚度 `100px`
- 点击扩散速度为 `240 × 3 = 720px/s`，`184px` 范围对应约 `255ms` 的注入时长
- 流体比例 `0.8`、扩散迭代 `5`、压力迭代 `10`
- 速度/密度耗散 `0.1`
- 全局速度系数 `0.5`、交互密度 `0.9`
- 拖拽阈值 `6px`、增强上限 `60px`

所有可调值都集中在 `ascii-hero.js` 顶部的 `ASCII_CONFIG`。

## 兼容策略

- DPR 最大为 `2`，ResizeObserver 会重建流体纹理和网格。
- `prefers-reduced-motion` 下关闭交互流体，保持纯色静态背景。
- 粗指针设备不启用 Hover/拖拽。
- 只依赖浏览器原生 Canvas 2D，不要求 WebGL 或浮点纹理扩展。

## 定制差异

- 原站以 `○>_ ` 作为默认亮度字符集；本版本按需求改为 `MINIMAX CODE `，并保留末位空格的遮罩语义。
- 原站 Hero 使用视频作为亮度输入；本版本按需求使用纯程序明暗场，演示包中不包含视频。
- 官方实现本身是 Canvas 2D CPU 流体，不是 WebGL Shader；本版本沿用同一算法结构，所以无需纹理 Y 翻转，`A` 会保持正常方向。
- 官方公开生产 bundle 仅作为研究依据；演示代码是独立、可读的 vanilla JavaScript 移植。
